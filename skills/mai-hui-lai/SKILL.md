# 麦回来

使用随包的 [产品档案](references/products.json) 作为有日期的研究起点。档案核对日是 2026-10-18；这里的名称、推广期和来源不能证明今天已停售。遵循用户选择的产品和城市，勿替换为同类名称。

## 整理回忆

- 对用户模糊名称保留原文与别名。冰桔茶 / 冰橘茶的 2016 年、约 2020 年都是用户回忆；2009—2018 是检索范围，不是证实销售期。没有公开记录时保留待考证状态。
- 先读具体官网历史页面，再查旧菜单或用户记录；存名称、类别、证据日期、日期含义、地区、原始链接、证据状态。旧促销期不是首发或最终停售时间。
- 保留三个分组：历史销售有出处、用户提名待考证、有区域回归公告。不同配方、冷暖版本、地区不要无依据合并。“同上”须回到对应来源解释。
- 图片需另核来源及使用权。可用文字卡片，不从相似产品推断真实外观。用户故事作为回忆引用，不提升为官方事实。

## 查今日线索

若已连接官方麦当劳 MCP，先发现当前 tools/list 和 inputSchema，只使用所需的只读查询工具。按实际 schema 填参；缺城市或工具必填信息时再询问，不能猜造字段。campaign-calendar 仅提供当月营销活动，不是完整历史数据库或全国库存。工具失败要说明未查成；没有查到不等于停售。地域回归公告不等于每家店今天可买。

需要配置时，指导用户在自己的 MCP 客户端以环境变量提供令牌，官方 Streamable HTTP 地址为 https://mcp.mcd.cn。不要让用户把令牌放入档案、前端、分享文案或提交仓库。不要调用领券、下单、支付等有副作用工具。

## 愿望清单与演示

将确认的历史记录与用户希望分开呈现；使用“想再尝一口”等友好文案，不作麦当劳官方承诺。若用户使用随项目的演示，心愿存入当前服务 SQLite，按匿名浏览器 Cookie 每款最多一份，可以撤回；默认按心愿数降序展示，同票保持档案顺序。数字是匿名浏览器记录，不是核实人数，不防刷。仅连接同一服务的访问者共享汇总，当前仅本机监听，未公开部署。旧 localStorage 票首次成功连接时幂等合并，提名仍只存浏览器，可自行导出。没有向官方提交通道，不得描述成已上线公共投票活动。

用户要求对外发送或发布时先准备有来源、无私人信息的可审阅内容；这个技能本身不代表向官方或第三方发消息的授权。
